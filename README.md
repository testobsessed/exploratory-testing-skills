# Exploratory Skills

A collection of reusable agent skills for exploratory testing.

## Skills

| Skill | Purpose |
| --- | --- |
| [Exploratory Session Log](skills/exploratory-session-log/SKILL.md) | Record a session with the charter first, append-only experiments and observations, and a findings summary for reporting or handoff. |

## Structure

Each skill lives in `skills/<skill-name>/` with a `SKILL.md` entry point and any supporting scripts, references, or assets it needs. Skills follow the [Agent Skills specification](https://agentskills.io/specification).
