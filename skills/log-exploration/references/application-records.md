# Shared Application Records Compatibility

The [canonical logger](../../exploratory-session-log/SKILL.md) governs defaults, location, and reporting. Read [shared application records](../../exploratory-session-log/references/application-records.md) only when maintaining indexes or reusable summaries, or coordinating multiple sessions. Reuse guidance already in context. Keep existing locations and history; this compatibility path does not require a second log or index.

For existing marker-based logs, retain the entry and continuation conventions in [session-notes.md](session-notes.md). Its question/setup/action/observation/interpretation/next labels describe legacy records; new sessions use the canonical Experiment/Observation structure. The legacy append helper requires Git; append directly when it cannot be used. Logging itself does not require Git.
